AKTUALIZACJA NA GITHUB PAGES
1. Rozpakuj archiwum ZIP.
2. Otwórz repozytorium Auto-Diag na GitHub.
3. Wybierz Add file -> Upload files.
4. Wgraj CAŁĄ zawartość folderu auto-diag-main i zastąp dotychczasowe pliki.
5. Zatwierdź przez Commit changes.
6. Po 1–3 minutach otwórz RESET.html i wyczyść poprzednią wersję aplikacji.
7. Otwórz Auto-Diag ponownie. Na pulpicie powinna być wersja V7.0.
